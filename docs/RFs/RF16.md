# **RF16 \- Receber a frequência cardíaca**  
O sistema deve receber, enquanto a conexão estiver ativa, as leituras de frequência cardíaca enviadas pela pulseira por meio do serviço GATT de frequência cardíaca.

Caso de Uso \- Receber a frequência cardíaca

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC16 |
| Nome | Receber a frequência cardíaca |
| Ator principal | Coletor BLE |
| Pré-condição | Pulseira conectada; serviço de frequência cardíaca disponível (RF07) |
| Pós-condição | Leituras de frequência cardíaca recebidas continuamente, com horário, enquanto a conexão estiver ativa |

**História de usuário:**  
Como coletor BLE, quero receber a frequência cardíaca da pulseira, para monitorar os sinais vitais do pesquisador.

**Critérios de aceitação:**

* Após conectar, o sistema deve ativar as notificações da característica de medição de frequência cardíaca (Heart Rate Measurement, 0x2A37).  
* Cada leitura deve conter a frequência cardíaca em bpm, os intervalos RR quando enviados pela pulseira e o horário de recebimento.  
* As notificações devem ser reativadas a cada nova conexão, inclusive após reconexão (RF05) e *handoff* (RF06).  
* O recebimento não deve interromper a leitura de RSSI (RF04) nem a conexão.  
* Se o serviço de frequência cardíaca não estiver disponível, o sistema deve registrar o erro servico-indisponivel e informar o motivo.  
* Se nenhuma leitura chegar por um tempo configurável (padrão de 5 s) com a conexão ativa, o sistema deve registrar o fato em *log*.
