# **RF02 \- Localizar a pulseira**  
O sistema deve realizar uma varredura (scan) e procurar por um endereço (endereço MAC) solicitado, exibindo: endereço, nome e RSSI.

Caso De Uso \- Localizar a pulseira

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC02 |
| Nome | Localizar a pulseira |
| Ator principal | Coletor BLE |
| Pré-condição | Bluetooth ligado |
| Pós-condição | A pulseira é identificada com seu endereço atual e RSSI, ou o estado nao-encontrado é registrado |

**História de usuário:**  
Como coletor BLE, quero localizar a pulseira pelo endereço, para identificá-la corretamente.  
**Critérios de aceitação:**

* Se o dispositivo for detectado, exibir endereço, nome (ou rótulo padrão) e RSSI em dBm.  
* O endereço alvo deve ser configurado via variáveis de ambiente (TARGET\_ADDRESS).  
* Se a pulseira não for detectada dentro do tempo limite configurável, o sistema deve registrar o estado nao-encontrado e o erro pulseira-nao-encontrada.  
* A busca deve terminar assim que o dispositivo for encontrado, sem esperar o fim do tempo limite.  
* O tempo limite da busca deve ser configurável (padrão de 10 s).  
* Se o Bluetooth estiver desligado, exibir mensagem orientando a ativá-lo  
* Funcionar sem acesso à internet
