# **RF13 \- Assinar mensagens dos demais coletores**  
O sistema deve receber, por meio do *broker*, a presença, o estado de conexão e o RSSI publicados pelos demais coletores, mantendo uma visão atualizada de cada um.

Caso de Uso \- Assinar mensagens dos demais coletores

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC13 |
| Nome | Assinar mensagens dos demais coletores |
| Ator principal | Coletor BLE |
| Pré-condição | Coletor conectado ao *broker* |
| Pós-condição | Visão atualizada dos coletores ativos, com estado e RSSI mais recentes de cada um |

**História de usuário:**  
Como coletor BLE, quero receber as mensagens dos demais coletores, para saber quem está ativo e com qual sinal, e decidir se devo iniciar ou aceitar um *handoff*.

**Critérios de aceitação:**

* O sistema deve assinar os tópicos de presença, estado/RSSI e *handoff* de todos os coletores (ex.: coletores/+/presenca).  
* O sistema deve ignorar as mensagens publicadas por ele mesmo.  
* Para cada coletor, o sistema deve manter o estado e o RSSI mais recentes, com o horário da última mensagem.  
* Um coletor sem sinal de vida por um tempo configurável (padrão de 15 s) ou com presença *offline* deve ser considerado indisponível.  
* Mensagens fora do formato definido devem ser descartadas e registradas em *log*, sem interromper o coletor.  
* Mensagens com *timestamp* mais antigo que o último recebido do mesmo coletor devem ser ignoradas.
