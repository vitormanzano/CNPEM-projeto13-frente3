# **RF07 \- Descobrir serviços da pulseira**  
O sistema deve listar os serviços GATT disponibilizados pela pulseira conectada, exibindo UUID e descrição de cada um.

Caso de Uso \- Descobrir serviços da pulseira

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC07 |
| Nome | Descobrir serviços da pulseira |
| Ator principal | Coletor BLE |
| Pré-condição | Pulseira conectada |
| Pós-condição | A lista de serviços GATT é exibida com UUID e descrição. |

   
**História de usuário**  
Como coletor BLE, quero descobrir os serviços oferecidos pela pulseira, para confirmar que ela disponibiliza os dados necessários (ex.: frequência cardíaca).

**Critérios de aceitação:**

* Cada serviço deve ser exibido com UUID e descrição.  
* O serviço de frequência cardíaca deve constar na lista da Polar Verity Sense.  
* Se a pulseira não estiver conectada, o sistema deve exibir mensagem informativa.
