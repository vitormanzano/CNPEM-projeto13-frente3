# **RF04 \- Ler RSSI da conexão ativa**  
O sistema deve ler o RSSI do dispositivo enquanto a conexão estiver ativa, em intervalo configurável.  
Caso de Uso \- Ler RSSI da conexão ativa

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC04 |
| Nome | Ler RSSI da conexão ativa |
| Ator principal | Coletor BLE |
| Pré-condição | Pulseira conectada; |
| Pós-condição | Exibir o RSSI mais recente do dispositivo. |

	  
**História de usuário**  
Como coletor BLE, quero verificar o RSSI do dispositivo que estou conectado, para identificar quando o pesquisador está se afastando e o sinal enfraquecendo.  
**Critérios de aceitação:**

* Exibir o RSSI mais recente em dBm, junto com o horário da leitura.  
* A leitura deve ser repetida em intervalo configurável (por exemplo, 500 ms a 1 s).  
* A leitura não deve interromper a conexão nem o recebimento dos dados fisiológicos.  
* Se a plataforma não permitir a leitura, informar que o RSSI está indisponível e o motivo.
