# **RF15 \- Padronizar as mensagens entre coletores**  
O sistema deve trocar mensagens com os demais coletores em formato e tópicos padronizados, com nível de entrega (QoS) definido para cada tipo de mensagem.

Caso de Uso \- Padronizar as mensagens entre coletores

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC15 |
| Nome | Padronizar as mensagens entre coletores |
| Ator principal | Coletor BLE |
| Pré-condição | Coletor conectado ao *broker* |
| Pós-condição | Mensagens publicadas e interpretadas no formato padronizado |

**História de usuário:**  
Como coletor BLE, quero que todas as mensagens sigam o mesmo formato, para que qualquer coletor consiga interpretá-las corretamente, mesmo após atualizações do sistema.

**Critérios de aceitação:**

* O conteúdo das mensagens deve ser JSON, contendo versão do formato, tipo da mensagem, identificador do coletor e *timestamp* (UTC).  
* Os tópicos devem seguir uma hierarquia única e documentada (ex.: coletores/{coletor}/presenca, coletores/{coletor}/pulseiras/{endereco}, pulseiras/{endereco}/posse).  
* Mensagens de posse e *handoff* devem usar QoS 1; leituras de RSSI podem usar QoS 0.  
* Mensagens de presença e posse devem ser retidas no *broker*.  
* Os termos usados nos campos e valores devem seguir a linguagem ubíqua (ex.: estados conectado, desconectado, conexao-fraca, nao-encontrado).  
* Mensagens com versão de formato incompatível devem ser descartadas e registradas em *log*.
