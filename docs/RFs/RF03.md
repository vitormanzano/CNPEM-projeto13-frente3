# **RF03 \- Conectar à pulseira**  
O sistema deve estabelecer uma conexão GATT com a pulseira localizada e mantê-la ativa enquanto o coletor for o responsável por ela.

Caso de Uso \- Conectar à pulseira

| Campo          | Descrição                                                                |
| :------------- | :----------------------------------------------------------------------- |
| Identificador  | UC03                                                                     |
| Nome           | Conectar à pulseira                                                      |
| Ator principal | Coletor BLE                                                              |
| Pré-condição   | Bluetooth ligado; dispositivo anunciado e não conectado a outro aparelho |
| Pós-condição   | Conexão GATT estabelecida e estado conectado registrado                  |

**História de usuário:**  
Como coletor BLE, quero me conectar à pulseira que está disponível para conexão, para conseguir usar os serviços do dispositivo BLE.  
**Critérios de aceitação:**

* Dado um endereço, o sistema deve conectar em até X segundos (configurável).  
* Ao concluir, o sistema deve informar o estado conectado e disponibilizar os serviços do dispositivo.  
* Se não conseguir conectar (tempo esgotado, dispositivo ausente ou ocupado), o sistema deve registrar o erro falha-conexao com o motivo.  
* O sistema deve permitir encerrar a conexão de forma controlada, liberando o dispositivo para outro coletor.  
* Enquanto conectado, o estado da conexão deve ser consultável.
