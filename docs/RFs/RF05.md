# **RF05 \- Reconectar automaticamente à pulseira**  
O sistema deve tentar reconectar à pulseira após uma queda inesperada, com limite de tentativas e intervalo configuráveis

Caso de Uso \- Reconectar automaticamente à pulseira

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC05 |
| Nome | Reconectar automaticamente à pulseira |
| Ator principal | Coletor BLE |
| Pré-condição | Conexão perdida (estado desconectado) sem handoff em andamento |
| Pós-condição | Conexão restabelecida, ou estado nao-encontrado após esgotar tentativas |

	  
**História de usuário:**  
Como coletor BLE, quero me reconectar com a pulseira após uma queda, para que o monitoramento do pesquisador não seja interrompido.  
**Critérios de aceitação:**

* Ao detectar a queda, o sistema deve iniciar a reconexão automaticamente, sem intervenção do usuário.  
* As tentativas devem respeitar o número máximo e o intervalo configurados.  
* Ao reconectar, o sistema deve reiniciar os fluxos de dados do dispositivo (a Polar exige o comando de início a cada conexão).  
* Ao reconectar, o estado deve voltar a conectado e o monitoramento de RSSI deve ser retomado.  
* Se esgotar as tentativas, o sistema deve informar a falha e mudar o estado para “desconectado”  
* Uma desconexão solicitada pelo próprio sistema (por exemplo, no handoff) não deve disparar reconexão automática.  
* Cada queda e cada reconexão devem ser registradas com horário.
