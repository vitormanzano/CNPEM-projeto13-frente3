# **RF06 \- Realizar handoff da pulseira entre coletores**  
O sistema deve transferir a conexão da pulseira de um coletor para outro quando o coletor atual estiver com conexão fraca e outro coletor detectar sinal melhor.

Caso de Uso \- Realizar *handoff* da pulseira entre coletores

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC06 |
| Nome | Realizar *handoff* da pulseira entre coletores |
| Ator principal | Coletor BLE |
| Pré-condição | Pulseira conectada ao coletor ativo; coletor de destino em operação e apto a conectar; RSSI filtrado abaixo do limiar; coletor atual em estado conexao-fraca |
| Pós-condição | A pulseira é conectada ao novo coletor e o coletor anterior fica desconectado dela |

**História do usuário:**  
Como coletor BLE, quero transferir a pulseira para outro coletor com sinal melhor quando a minha conexão enfraquecer, para que o pesquisador continue sendo monitorado ao se deslocar pelo laboratório.

**Critérios de aceitação:**	

* Quando o RSSI filtrado do coletor ativa ficar abaixo do limiar e outro coletor estiver melhor pela margem configurada, a transferência deve iniciar automaticamente.  
* Após a troca, a pulseira deve estar conectada a um único coletor ativo, sem dados duplicados para os consumidores.  
* Se o destino não conectar no tempo limite, a origem deve reconectar.  
* O tempo total sem conexão durante o handoff deve ser registrado em log.  
* Cada troca deve ser registrada com origem, destino, RSSI e duração da lacuna de dados.
