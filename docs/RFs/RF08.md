# **RF08 \- Determinar o estado da conexão**  
O sistema deve classificar continuamente o estado da conexão do coletor com a pulseira em: conectado, desconectado, nao-encontrado. O estado conexao-fraca é determinado pelo coordenador a partir do RSSI publicado (RF19).

Caso de Uso \- Determinar o estado da conexão

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC08 |
| Nome | Determinar o estado da conexão |
| Ator principal | Coletor BLE |
| Pré-condição | Monitoramento em execução |
| Pós-condição | Estado da conexão atualizado e registrado |

    
**História de usuário:**  
Como coletor BLE, quero classificar o estado da minha conexão com a pulseira, para que o coordenador saiba quando a conexão foi estabelecida, perdida ou a pulseira não foi localizada.

**Critérios de aceitação:**

* O estado deve ser conectado quando a conexão GATT for estabelecida.  
* O estado deve ser desconectado quando a conexão for perdida ou encerrada de forma controlada (RF10).  
* O estado deve ser nao-encontrado quando a pulseira não for localizada na varredura.  
* O coletor não deve classificar a qualidade do sinal; a classificação conexao-fraca cabe ao coordenador (RF19).  
* Toda mudança deve ser registrada em *log* com *timestamp*, estado anterior, estado novo e motivo.
