# **RF08 \- Determinar o estado da conexão**  
O sistema deve classificar continuamente o estado da conexão com a pulseira em: conectado, desconectado, conexao-fraca, nao-encontrado.

Caso de Uso \- Determinar o estado da conexão

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC08 |
| Nome | Determinar o estado da conexão |
| Ator principal | Coletor BLE |
| Pré-condição | Monitoramento em execução |
| Pós-condição | Estado da conexão atualizado e registrado |

    
**História de usuário:**  
Como coletor BLE, quero classificar o estado da minha conexão com a pulseira, para que o sistema saiba quando é necessário reconectar ou realizar o *handoff*

**Critérios de aceitação:**

* O estado deve ser  conexao-fraca quando o RSSI estiver abaixo de um limiar configurável (ex.: \-80 dBm) por um número configurável de leituras consecutivas.  
* O estado deve voltar a conectado quando o RSSI se recuperar acima do limiar.  
* O estado deve ser desconectado quando a conexão for perdida.  
* O estado deve ser nao-encontrado quando a pulseira não for localizada na varredura  
* Toda mudança deve ser registrada em *log* com *timestamp*.
