# **RF09 \- Publicar estado e RSSI no *broker***  
O sistema deve publicar no broker MQTT as leituras de RSSI e as mudanças de estado de conexão de cada coletor.

Caso de Uso \- Publicar estado e RSSI no broker

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC09 |
| Nome | Publicar estado e RSSI no *broker* |
| Ator principal | Broker |
| Pré-condição | Coletor conectado à rede e ao *broker* |
| Pós-condição | Mensagem publicada no tópico correspondente ao coletor/pulseira |

    
**História de usuário:**

Como coletor BLE, quero publicar meu estado de conexão e RSSI no *broker*, para que o coordenador saiba quem está em melhor condição de atender a pulseira.

**Critérios de aceitação:**

* A mensagem deve conter identificador do coletor, endereço da pulseira, RSSI, estado e *timestamp*  
* O tópico deve identificar o coletor e a pulseira (ex.: coletores/{coletor}/pulseiras/{endereco}.  
* O endereço e a porta do *broker* devem ser configuráveis.  
* Se o *broker* estiver indisponível, o sistema deve registrar o erro broker-indisponivel, manter a conexão BLE e tentar reconectar ao *broker*.  
* A falha no broker não deve interromper o monitoramento da pulseira
