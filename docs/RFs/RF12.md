# **RF12 \- Anunciar presença do coletor**  
O sistema deve informar ao coordenador, por meio do *broker*, se o coletor está *online* ou *offline*, inclusive em caso de queda inesperada.

Caso de Uso \- Anunciar presença do coletor

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC12 |
| Nome | Anunciar presença do coletor |
| Ator principal | Coletor BLE |
| Pré-condição | Coletor conectado ao *broker* |
| Pós-condição | Presença do coletor publicada no tópico de presença e atualizada a cada mudança |

**História de usuário:**  
Como coletor BLE, quero anunciar minha presença ao coordenador, para que ele saiba quem está disponível para receber a pulseira em um *handoff*.

**Critérios de aceitação:**

* Ao conectar ao *broker*, o sistema deve publicar a presença *online* em mensagem retida (ex.: coletores/{coletor}/presenca).  
* O sistema deve registrar no *broker* uma mensagem de última vontade (*Last Will*) *offline*, publicada automaticamente se o coletor cair sem avisar.  
* Ao encerrar de forma controlada, o sistema deve publicar a presença *offline* antes de desconectar.  
* O sistema deve publicar um sinal de vida (*heartbeat*) em intervalo configurável (padrão de 5 s).  
* A mensagem de presença deve conter identificador do coletor, estado (*online*/*offline*), pulseira atendida (quando houver) e *timestamp*.
