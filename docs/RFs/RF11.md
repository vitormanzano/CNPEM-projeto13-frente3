# **RF11 \- Conectar ao *broker***  
O sistema deve estabelecer e manter uma conexão MQTT entre o coletor e o *broker*, identificando o coletor de forma única.

Caso de Uso \- Conectar ao *broker*

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC11 |
| Nome | Conectar ao *broker* |
| Ator principal | Coletor BLE |
| Pré-condição | Coletor conectado à rede local; endereço, porta e credenciais do *broker* configurados |
| Pós-condição | Sessão MQTT ativa com o *broker*, identificada pelo identificador do coletor |

**História de usuário:**  
Como coletor BLE, quero me conectar ao *broker*, para trocar mensagens com os demais coletores e participar do *handoff*.

**Critérios de aceitação:**

* O endereço, a porta e as credenciais do *broker* devem ser configuráveis via variáveis de ambiente.  
* O identificador do coletor (client id) deve ser configurável e único entre os coletores.  
* Ao conectar, o sistema deve registrar em *log* o sucesso da conexão com horário.  
* Se o *broker* estiver indisponível, o sistema deve registrar o erro broker-indisponivel e tentar reconectar em intervalo configurável, sem encerrar o coletor.  
* A conexão com o *broker* não deve depender da conexão BLE, e a falha de uma não deve interromper a outra.  
* Ao reconectar, o sistema deve refazer as assinaturas de tópicos automaticamente.  
* Funcionar sem acesso à internet, apenas com o *broker* na rede local.
