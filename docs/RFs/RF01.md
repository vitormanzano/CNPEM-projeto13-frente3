# **RF01 \- Listar dispositivos BLE no local**  
O sistema deve realizar uma varredura (scan) e listar os dispositivos BLE que estão anunciando (advertising) ao alcance do coletor, exibindo para cada um: endereço (endereço MAC), nome (quando disponível) e RSSI.

Caso De Uso Listar dispositivos BLE no local

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC01 |
| Nome | Listar dispositivos BLE no local |
| Ator principal | Coletor BLE |
| Pré-condição | Suporte a BLE; Bluetooth ligado. |
| Pós-condição | A lista de dispositivos detectados é exibida com endereço, nome (quando houver) e RSSI |

	  
**História de usuário:**  
Como coletor BLE, quero listar os dispositivos BLE que estão anunciando ao meu alcance, para verificar se a pulseira está detectável e com qual intensidade de sinal antes de iniciar a conexão.  
**Critérios de aceitação:**

* Cada item da lista deve exibir endereço, nome e RSSI (em dBm).  
* Dispositivos sem nome devem aparecer com um rótulo padrão.  
* Um mesmo dispositivo deve aparecer apenas uma vez na lista, com o RSSI mais recente.  
* A Polar Verity Sense deve aparecer quando estiver ligada, ao alcance.  
* Se o Bluetooth estiver desligado, o sistema deve exibir mensagem informativa orientando a ativá-lo.  
* Se nenhum dispositivo for encontrado, o sistema deve exibir mensagem informativa.  
* A funcionalidade deve operar sem acesso à internet.  
* A varredura deve durar um tempo configurável (padrão de 10 s).
